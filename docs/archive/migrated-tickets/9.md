## Original issue body

## Problem

Editing any meet help text — top-level usage or any subcommand's `-h` output — requires editing Go source in `cmd/meet/main.go` and rebuilding. #8 established the pattern for meet-helper (canonical text in `docs/help/`, staged into the binary's package dir at build time, embedded via `//go:embed`). The meet binary was not migrated in the same change.

## Out of scope

- Changing the content of any help text. This is a refactor.
- Removing the auto-generated flag descriptions produced by `flag.FlagSet.PrintDefaults`. They stay; only the prose surrounding them moves.

## Solution outline

Mirror the meet-helper pattern:

- Canonical sources under `docs/help/meet.txt`, `docs/help/meet-serve.txt`, `docs/help/meet-token.txt`, `docs/help/meet-create.txt`, `docs/help/meet-cancel.txt`, `docs/help/meet-list.txt`.
- Makefile `stage-help-text` target gains lines that copy each source into `cmd/meet/`.
- `cmd/meet/main.go` embeds the staged files via `//go:embed`.
- Each `fs.Usage` prints the embedded prose, then `fs.PrintDefaults()` for the auto-synced flag block.
- Staged copies under `cmd/meet/` are gitignored.
