## Original issue body

## Problem

The create CLI mixed a timestamped `--from` (with `Z`) with `--tz`, which is contradictory, and weekly took its time from `--from` while monthly used `--at` — inconsistent and imprecise.

## Change (hard break; sole operator)

- `--from` is a bare date `YYYY-MM-DD`; a time, `Z`, or offset on it is an error.
- `--until` removed entirely (error); one-off length is `--duration`.
- `--at HH:MM` mandatory except when `--on <date>` is the sole date argument; minute granularity (no seconds).
- `--tz` sets the zone for `--at` (one-off and recurring alike); default UTC.
- Recurring uses explicit `--weekday` (weekly too, not derived from --from) and optional `--from` (default now = series start); monthly adds `--ordinal`.

**Grammar changes**
- `--from` is now a bare date `YYYY-MM-DD`; a value carrying a time is rejected (`--from must be a bare date YYYY-MM-DD (use --at for the time)`).
