## Original issue body

## Problem

The Makefile `release` target ran its own `git describe`-based version increment and `git tag`/`git push`. Version tagging is not a requirement of this project and is handled by the operator externally (`~/bin/tagp`). The inline increment also mis-parsed three-part `v0.0.x` versions (it read only `major.minor`, dropping the patch), so from `v0.0.18` it would produce `v0.1` and push it.

## Change

Remove the `release` target, its `.PHONY` entry, and the `make release` line from the README targets list. Tagging remains solely with the operator.
