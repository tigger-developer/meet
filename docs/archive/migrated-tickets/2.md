## Original issue body

## Problem

The `CHAT_UPLOADED` webhook payload does not include `startTimestamp`, so the filename defaults to the Unix epoch: `workshop5_1970-01-01_0000_chat.json`.

## Expected

The filename should use a meaningful timestamp. Fallback to the webhook `timestamp` field (delivery time) when `startTimestamp` is 0 or missing.

## Observed

`workshop5_1970-01-01_0000_chat.json` instead of `workshop5_2026-04-30_0020_chat.json`.
