## Original issue body

## Problem

During the Ubuntu-to-Nix VPS transition, Nix hosts allocate a port at deploy time via the `ADDR` environment variable. Ubuntu hosts set `addr` in config YAML. Currently `ADDR` is not read from the environment at all — the bind address comes exclusively from config YAML (with a hardcoded default of `127.0.0.1:18085`).

Both deployment models must coexist during the transition. `ADDR` as an env var must take precedence over `addr` in config YAML so that Nix-allocated ports are honoured.

## Solution

After `loadConfig()` returns, check `os.Getenv("ADDR")`. If set, override `cfg.Addr` with its value. This gives the env var highest precedence in the chain: default → config YAML → `ADDR` env var.

The change is 5 lines in `cmd/meet/main.go`.
